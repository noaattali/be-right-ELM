This folder contains the material for the paper “A tale of two predicates: Predicting projection variation between know and be right”, that is, the investigation of the difference in the projection patterns of BEL and CC in negative know-utterances versus negative be right-utterances.

The folder contains the following directories:

/model: The model reported on in the paper:

- model_ELM.wppl - the model reported in the paper

- model_ELM_evaluation.R - R code for model evaluation and figures

- data/ - model outputs

- graphs/ - model predictions figures, including those in the paper
